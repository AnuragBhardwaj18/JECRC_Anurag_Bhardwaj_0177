### `npm run eject`

**Note: this is a one-way operation. Once you `eject`, you can't go back!**

If you aren't satisfied with the build tool and configuration choices, you can `eject` at any time. This command will remove the single build dependency from your project.

Instead, it will copy all the configuration files and the transitive dependencies (webpack, Babel, ESLint, etc) right into your project so you have full control over them. All of the commands except `eject` will still work, but they will point to the copied scripts so you can tweak them. At this point you're on your own.

You don't have to ever use `eject`. The curated feature set is suitable for small and middle deployments, and you shouldn't feel obligated to use this feature. However we understand that this tool wouldn't be useful if you couldn't customize it when you are ready for it.

Enterprise E-Commerce Application
A company is developing a large-scale e-commerce web application using React. The application must support multiple user roles and provide different user experiences based on authentication and functionality.

The application is divided into three major sections:

1. Public Website (MainLayout)
This section is accessible to all users and includes:

Home page
About page
Contact page
It contains a common layout with a sidebar, header, and footer for consistent branding and navigation.

2. Authentication Module (AuthLayout)
This section includes:

Login page
Registration page
It uses a minimal layout without header or footer to keep the interface focused. After successful login, users are redirected to the dashboard.

3. Dashboard Module (DashboardLayout)
This section is accessible only to authenticated users and includes:

Dashboard Home
Analytics page
Settings page
A Protected Route mechanism is implemented to prevent unauthorized access. If a user tries to access dashboard routes without logging in, they are redirected to the login page.

4. Product Module (Dynamic + Nested Routing)
The application also includes a product management system:

/products → Displays product list
/products/:productId → Displays product details
Each product detail page contains nested sections:

/reviews → Customer reviews
/specs → Product specifications
This structure uses dynamic routing and nested routing to organize related content efficiently.
